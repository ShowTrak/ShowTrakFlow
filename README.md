# ShowTrak Flow

**Follow every group of guests through a pulsed-entry show.**

_In development: not yet released._

[Website](https://showtrak.co.uk/software/flow) · [Discord](https://discord.gg/DACmwsbSGW)

[![Windows][badge-windows]](https://showtrak.co.uk/software/flow) [![macOS][badge-macos]](https://showtrak.co.uk/software/flow) [![Linux][badge-linux]](https://showtrak.co.uk/software/flow)

</div>

ShowTrak Flow is for immersive and pulsed-entry shows, where audiences go through the show in
groups. It tracks where each group is, how long it has been in each scene and what the team needs
to know about it.

## Key features

- **Flows**: save the running order for each kind of day ("Weekday", "Bank Holiday") and load it at the start of a show.
- **Live queue**: see upcoming groups and change them on the day without touching the saved flow. It survives a restart.
- **Scenes**: follow each group through the show scene by scene, with progress bars and markers for key moments.
- **Notes and flags**: tag groups with flags (birthdays, access needs, VIPs) and notes the whole team can see.
- **Team chat**: chat rooms per scene and for the whole team.
